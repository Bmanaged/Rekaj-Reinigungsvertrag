# Reinigungsvertrag – Rekaj Reinigung

Interaktive Vertrags-Vorlage als **eine einzige HTML-Datei** – keine
Abhängigkeiten, kein Build, kein Server. Läuft direkt im Browser und wird
über **GitHub Pages** veröffentlicht.

## Was die Seite kann

- Vertragsdaten (Auftraggeber, Einsatz, Rhythmus, Vergütung, MWST, Zonen …)
  interaktiv erfassen – die Zusammenfassung wird live berechnet.
- Vertrag elektronisch abschliessen oder eine **E-Mail-Bestätigung** anfordern.
- Vertrag als PDF speichern / drucken (Druckansicht integriert).

## E-Mail

Der Versand läuft über den `mailto:`-Mechanismus, d. h. die E-Mail wird im
Mailprogramm des Geräts geöffnet und von dort gesendet. Als Kontakt- und
Kopieadresse (CC) ist durchgehend **info@rekaj-reinigung.ch** hinterlegt.

> Hinweis: Welche Absenderadresse in der gesendeten Mail erscheint, bestimmt
> das verwendete Mailkonto – eine Webseite kann den Absender technisch nicht
> erzwingen. Für einen einheitlichen Absender **info@rekaj-reinigung.ch** muss
> dieses Konto im Mailprogramm eingerichtet und beim Senden ausgewählt sein.

## Lokal starten

Datei `index.html` einfach im Browser öffnen. Kein Build, kein Server nötig.

## Deployment

Statische Seite über **GitHub Pages** (Branch `main`, Wurzelverzeichnis).
Jeder Push auf `main` aktualisiert die veröffentlichte Seite automatisch.
